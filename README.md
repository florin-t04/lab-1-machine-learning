# lab-1-machine-learning

Acest laborator introductiv de Machine Learning utilizează setul de date Iris pentru analiza exploratorie a datelor. Exercițiile includ încărcarea și curățarea datelor, statistici descriptive și agregări pe specii, precum și vizualizări cu Matplotlib și Seaborn: histograme, pairplot, boxplot și hartă de corelație. Sunt abordate concepte introductive despre framework-uri și pregătirea necesară pentru curs.
- Iris_Data.csv - data set-ul utilizat
- 01_Introduction_to_Machine_Learning_and_Toolkit.ipynb - ghid introductiv
- 01_RO_Lab1_.ipynb - condițiile exercițiilor
- 01_Trandafir.ipynb - exercițiile realizate
